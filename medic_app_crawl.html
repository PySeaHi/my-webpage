01

抓包，看到请求长什么样

通过 Charles/Fiddler/mitmproxy 等抓包工具，捕获多次请求，观察参数差异。

{
  "clientType": "1",
  "deCode": "37a66d10ebe6d596",
  "sign": "9899e80d...",
  "sortTime": 1788310079152,
  "timestamp": 1789561029662
}
02

判断哪些参数是翻页参数

对比多次请求，sortTime 递减、timestamp 递增，确认是时间戳游标分页。

sortTime：递减 → 翻页游标 timestamp：递增 → 防重放 sign：每次变化 → 签名校验
03

sign 是最大的拦路虎

手动修改 sortTime 但 sign 不更新会被服务端拒绝：{"code":1,"msg":"网络开小差了"}

⚠️ 第一次尝试失败：误将腾讯 openSDK 的 i.b 当作签名方法，Frida Hook 验证未被调用。
04

用 Frida 定位签名逻辑

Hook MessageDigest.digest 并打印调用栈，从调用栈找到真正的签名类。

✅ 定位到：com.people.health.doctor.net.RequestData
05

读懂签名算法源码

通过 jadx 反编译 APK，阅读 RequestData 类源码，提炼签名算法。

📝 算法逻辑：
  1. 参数存入 TreeMap，按 key 字典序排序
  2. 拼接：key=Hg3c^Tqj5twmkgSNmxte7fNfvsp%DD2v&k1=v1&k2=v2...
  3. sign 字段本身不参与签名，null 值跳过
  4. 对拼接字符串做 UTF-8 MD5，输出小写 hex
06

用 Python 复现签名

使用 Hook 到的真实样本验证算法，自检通过即 100% 复现。

def gen_sign(params: dict) -> str:
    items = sorted(params.items(), key=lambda kv: kv[0])
    parts = [f"key={SALT}"]
    for k, v in items:
        if v is None: continue
        parts.append(f"{k}={v}")
    raw = "&".join(parts)
    return hashlib.md5(raw.encode("utf-8")).hexdigest()

import hashlib
import time
import json
import requests

SALT = "Hg3c^Tqj5twmkgSNmxte7fNfvsp%DD2v"
URL = "YUhSMGNITTZMeTlvZVhNdWNHVnZjR3hsTFdobFlXeDBhQzVq..."

LIST_PATH    = ("data", "articles")
CURSOR_FIELD = "sortTime"
ID_FIELD     = "id"
PAGE_LIMIT   = 1000
SLEEP        = 0.5
OUT_FILE     = "articles.jsonl"


def gen_sign(params):
    """生成签名：key=盐&按key排序的k=v对"""
    items = sorted(params.items(), key=lambda kv: kv[0])
    parts = [f"key={SALT}"]
    for k, v in items:
        if v is None:
            continue
        parts.append(f"{k}={v}")
    raw = "&".join(parts)
    return hashlib.md5(raw.encode("utf-8")).hexdigest()


def build_params(sort_time):
    """构造请求参数"""
    p = {
        "clientType": "1",
        "deCode": "37a66d10ebe6d596",
        "model": "google Pixel 4",
        "osType": "10",
        "sortTime": sort_time,
        "timestamp": int(time.time() * 1000),
        "uid": "-1",
        "v": "2.2.143",
    }
    p["sign"] = gen_sign(p)
    return p


def fetch_page(sort_time):
    """请求单页数据"""
    params = build_params(sort_time)
    headers = {
        "Content-Type": "application/json; charset=UTF-8",
        "User-Agent": "okhttp/4.x",
    }
    r = requests.post(URL, data=json.dumps(params), headers=headers, timeout=15)
    return r.json()


def get_list(data):
    """安全获取列表字段"""
    cur = data
    for key in LIST_PATH:
        if not isinstance(cur, dict) or key not in cur:
            return []
        cur = cur[key]
    return cur if isinstance(cur, list) else []


def main():
    sort_time = int(time.time() * 1000)
    seen = set()
    total = 0
    out = open(OUT_FILE, "w", encoding="utf-8")

    for page in range(PAGE_LIMIT):
        print(f"\n[page {page}] sort_time = {sort_time!r}")
        try:
            data = fetch_page(sort_time)
        except Exception as e:
            print("  请求失败:", e)
            time.sleep(2)
            continue

        print("  code =", data.get("code"), " msg =", data.get("msg"))
        items = get_list(data)
        print(f"  返回 {len(items)} 条")

        if not items:
            print("  空列表，停止")
            break

        new_count = 0
        for item in items:
            uid = item.get(ID_FIELD)
            if uid is not None:
                if uid in seen:
                    continue
                seen.add(uid)
            out.write(json.dumps(item, ensure_ascii=False) + "\n")
            new_count += 1

        total += new_count
        print(f"  新增 {new_count} 条，累计 {total} 条")

        last = items[-1]
        next_cursor_raw = last.get(CURSOR_FIELD)
        if next_cursor_raw is None:
            print("  没有游标字段，停止")
            break

        next_cursor = int(next_cursor_raw)
        if next_cursor == sort_time:
            print("  游标未变化，停止")
            break

        sort_time = next_cursor
        time.sleep(SLEEP)

    out.close()
    print(f"\n完成，共保存 {total} 条到 {OUT_FILE}")


if __name__ == "__main__":
    main()
// hook.js - Frida Hook 签名方法
Java.perform(function () {
    // Hook 真正的签名类
    var RequestData = Java.use("com.people.health.doctor.net.RequestData");
    RequestData.getSignString.implementation = function () {
        var ret = this.getSignString();
        console.log("========== getSignString ==========");
        console.log(ret);
        return ret;
    };

    // Hook MD5 计算方法
    var x0 = Java.use("ae.x0");
    x0.b.overload('java.lang.String').implementation = function (s) {
        var ret = this.b(s);
        console.log("[x0.b] input = " + s);
        console.log("[x0.b] sign  = " + ret);
        return ret;
    };

    // ========== 通用：Hook MessageDigest 找调用栈 ==========
    var MessageDigest = Java.use("java.security.MessageDigest");
    MessageDigest.digest.overload().implementation = function () {
        var result = this.digest();
        var algo = this.getAlgorithm();
        var hex = "";
        for (var i = 0; i < result.length; i++) {
            var b = (result[i] & 0xff).toString(16);
            if (b.length == 1) b = "0" + b;
            hex += b;
        }
        console.log("[digest] algo=" + algo + " hex=" + hex);
        console.log(Java.use("android.util.Log")
            .getStackTraceString(Java.use("java.lang.Throwable").$new()));
        return result;
    };
});

import sys

JS = open("hook.js", encoding="utf-8").read()

def on_message(msg, data):
    """Frida 消息回调"""
    if msg["type"] == "send":
        print("[JS]", msg["payload"])
    else:
        print("[ERR]", msg)

# 使用 remote 设备（适用于 frida-server 端口转发）

front = rdev.get_frontmost_application()
print("front:", front)

session = rdev.attach(front.pid)
script = session.create_script(JS)
script.on("message", on_message)
script.load()

实战经验

九大常见坑点与解决方案

真实项目里大部分时间都花在调试，这些坑都是踩过的

1

sortTime = -1 返回空

原因：JSON 序列化成了字符串 "-1"，服务端 Long 解析失败。

✅ 解决：确保是数字类型 -1，不是字符串。

2

列表路径取错

原因：误以为是 data.list，实际是 data.articles。

✅ 解决：先打印完整返回结构，再确定字段路径。

3

游标字段类型问题

原因：返回的 sortTime 是字符串，传参需要数字。

✅ 解决：下一页传参用 int(last["sortTime"]) 转换。

4

找错签名类

原因：Hook 了腾讯 openSDK 的类，实际没被调用。

✅ 解决：Hook MessageDigest.digest + 打印调用栈定位。

5

Frida 通道问题

原因：frida -U 走 USB，get_remote_device() 走 remote。

✅ 解决：用 Python 加载脚本最稳，或指定 -H 127.0.0.1:27042。

6

签名参数顺序

原因：Java 用 TreeMap 按 key 字典序排序，Python 字典无序。

✅ 解决：sorted(params.items()) 排序后再拼接。

7

sign 参与了签名

原因：getSignString() 里会先 remove sign 再拼串。

✅ 解决：算 sign 时参数里不要包含 sign 字段本身。

8

时间窗口校验

原因：timestamp 和服务器时间差太多会被拒绝。

✅ 解决：保证本机时间准确，或用 NTP 同步。

9

频率限制风控

原因：请求太猛会触发风控、封 IP。

✅ 解决：每页 sleep 0.5~2 秒，加上代理池。

知识总结与方法论

不仅是一个案例，更是一套可复用的逆向方法论

核心方法论

1
先观察，再动手

对比多次请求，找变化字段，不要上来就瞎猜。

2
从已知推未知

先用真实样本自检算法，再推广到通用情况。

3
Hook 优于猜

找不到类时，Hook 底层 API + 调用栈是杀手锏。

4
打印真实数据

不要凭想象，getSignString 一打印就什么都清楚了。

5
类型要对齐

Java Long vs JSON 字符串 vs Python int，是最常见的坑。
